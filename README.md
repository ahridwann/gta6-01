Neon Harbor is a three.js open-world driving and action game set in Porto Solmar, where getaway driver Dario "D" Cruz steals cars, outruns the harbor police, and runs three story missions.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. WASD to move/drive, mouse to look, E to steal or exit a car, F to punch, click to shoot, M for the next mission, P to pause.
